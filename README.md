# LORDE

Sistema operacional pessoal de inteligência artificial.

## Fundação — v0.1

Primeira versão criada para estabelecer uma base limpa e escalável para:

- Dashboard central
- Chat com o LORDE
- Agentes especializados
- Projetos
- Automações
- Integrações externas
- Memória e contexto

## Stack inicial

- React
- TypeScript
- Vite

## Desenvolvimento

```bash
npm install
npm run dev
```

## Direção do produto

O LORDE será construído de forma modular. Cada nova capacidade deve ser adicionada sem comprometer a fundação existente.
